# Repository skills

## Documentation language

All documentation produced or maintained through a skill must be in English, including release notes, benchmark reports, explanatory comments, and chart labels. Translate existing German documentation without changing its technical meaning or measurements. Preserve original logs and raw measurement records. Follow [AGENTS.md](AGENTS.md).

## Available workflow

- [Publish an ErgoMetal release](.agents/skills/publish-ergometal-release/SKILL.md): build, sign, notarize, and publish an explicitly requested release. Editing documentation or skill instructions alone does not invoke a production release.

This file is a repository guide. The discoverable skill entrypoint is the linked `SKILL.md`.
