# Release 2026-09-05

This release fixes shutdown accounting, stale reconnect callbacks, pool-error
redaction, concurrent JSONL appends, fragmented HTTP requests, and invalid
autotuning cache values. It also makes Dataset builds observe the autotuning
budget between chunks, draining already queued work before returning.

SIGINT and SIGTERM now request cancellation first. The mining loop drains
Search work and flushes its counters before writing a single final
`session_ended`. Recipient changes and successful user authorization invalidate
older reconnects. Pool share errors retain numeric protocol codes without
copying free-form replies into logs; configured sensitive values are redacted
from other pool diagnostics.

The statistics server assembles headers across TCP reads with an 8 KiB limit
and five-second timeout. Event files use atomic creation, append mode, and file
locking so independent writers preserve complete JSONL records. Cached
execution values must satisfy numeric bounds, SIMD widths, and GPU pipeline
limits before use.

## Validation

- 77 tests passed in Debug and 77 in optimized Release, with no failures or
  skipped tests. Release tests explicitly enable testability; the distributed
  executable is built without that override.
- Benchmark campaign regression and shell syntax checks passed.
- A local Stratum integration run stopped cleanly on SIGINT. Its 8,106
  completed Search commands matched all 8,300,544 nonces in the sole final
  event. No public pool was contacted.
- Standalone packaging passed its isolated Metal smoke benchmark.
- Swift compilation uses `-O` and whole-module optimization without debug
  information. Metal compilation uses fast math without debug or source
  recording flags. The compiled AIR contains no DWARF debug metadata.
- The stripped executable is arm64-only, embeds `__TEXT,__metallib`, has no
  `__DWARF` segment or debug symbol entries, and links only system libraries.
- Developer ID signing with Hardened Runtime passed strict verification.
  Apple notarization returned `Accepted`, `Ready for distribution`, and no
  issues. The ticket's CDHash matches the executable.
- Gatekeeper recognizes the notarized executable as valid code, with the
  expected indication that this bare command-line tool is not an app bundle.

The Metal kernel and conservative execution defaults are unchanged. This is a
correctness release; it does not establish a new mining throughput gain.
